# Introduction

HiveSync is a **simple and modern task management platform** built with a **single-tenant, API-driven architecture**. It allows users to manage:

- Todos
- Projects
- Sections inside Projects
- User authentication
- Email notifications

The backend uses **CQRS, the Repository Pattern, and MediatR** to separate commands from queries and maintain clean, maintainable code.  
The frontend is built in **React** for a responsive and interactive user experience.

HiveSync is designed for **ease of use**, simplicity in setup, and extensibility for future features.
